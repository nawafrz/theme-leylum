# Leylum — قالب سلة (Twilight)

قالب متجر بأسلوب تحريري هادئ لمتاجر العناية والجمال: خلفيات رملية دافئة، فواصل شعرية،
أزرار حبّية (pill)، لمسات سيريف Amiri، وعمق ناعم مع حركة مدروسة.
مبني على القالب الرسمي [Raed](https://github.com/SallaApp/theme-raed) — كل مزايا رائد تعمل كما هي.

## ما الذي يضيفه القالب
- طبقة هوية كاملة `src/assets/styles/06-leylum/leylum.scss` (تُحمَّل أخيرًا فتتقدم على أنماط رائد)
- خطوط ليلوم اختيارية: Tajawal للنصوص وAmiri للعناوين المائلة — إعداد `use_leylum_fonts` قابل للإيقاف
- هيدر لاصق بضبابية زجاجية عند التمرير، شريط إعلانات بلون منسجم (تُحترم ألوان التاجر إن ضُبطت)
- بطاقات منتجات كريمية مرتفعة عند المرور، حقول وأزرار حبّية، أكورديونات ناعمة في صفحة المنتج
- تذييل فاتح بعلامة Amiri كبيرة (`store.name`) — يحترم إعداد "تذييل داكن" إن فُعِّل
- حبيبات فيلم خفيفة على الشاشات الكبيرة توحّد الصور والأسطح (تُعطَّل مع تقليل الحركة)

## فئة مساعدة للمحررين
لفّ أي كلمة داخل وصف/محتوى HTML بـ `<span class="leylum-accent">…</span>`
لإظهارها بخط Amiri المائل — لمسة ليلوم المميزة في العناوين.

## البناء
```bash
pnpm install
pnpm run production   # يبني إلى public/
```

|---|---|---|

— صُنع بعناية في الرياض.
